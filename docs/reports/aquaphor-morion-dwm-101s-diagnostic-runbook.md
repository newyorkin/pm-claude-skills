## 1. Identify

**Система:** Аквафор Морион DWM-101S (обратный осмос под мойку).

| Позиция | Модуль | Роль |
|---|---|---|
| 1 | **K5** | Предфильтр (механика ≥5 мкм) |
| 2 | **K2** | Уголь / хлор / органика / металлы |
| 3 | **K-50S** (КО-50S) | Мембрана RO (верхний дренаж) |
| 4 | **K7M** | Постфильтр + минерализатор |

**Как обычно описывают проблему:**
- «Вода солоноватая / жёсткая / накипь снова есть»
- «TDS на чистом кране высокий»
- «Вкус/запах хлора»
- «Минерализация не чувствуется / TDS не растёт после минерализатора»
- «Пора по календарю менять»

**Часто путают с:**
- DWM-101 (без **S**) — нужна мембрана **K-50**, не K-50S
- Комплектом «без мембраны» vs полный комплект
- Высоким TDS из-за минерализатора (это нормально) vs из-за убитой мембраны

## 2. Severity / triage

| Уровень | Сигнал | Срок |
|---|---|---|
| **P1 — срочно** | Хлор обнаружен после K5+K2 (перед мембраной) | Менять **K5+K2 сегодня**; мембрану проверить TDS |
| **P2 — по факту** | TDS чистой воды **>10%** от TDS входа | Менять **K-50S** |
| **P2 — по факту** | С минерализатором TDS ≈ TDS после мембраны (не растёт) | Менять **K7M** |
| **P3 — план** | Прошло ≥6 месяцев с замены препфильтров | Превентивно **K5+K2** |

### 3.2. Инструкция: TDS-метр (TDS-3 и аналоги)

1. Набери ~50–100 мл воды в чистый стакан (не из посудомойки с остатками соли/моющего).
2. Сними защитный колпачок с электродов.
3. Нажми **On/Off**.
4. Опусти электроды в воду **до метки** на корпусе (не глубже — корпус не герметичен).
5. Слегка помешивай **10–20 секунд**, пока число на экране не стабилизируется.
6. Запиши значение в **ppm**. При необходимости нажми **Hold**.
7. Протри электроды чистой тканью, надень колпачок.

**Типичные показания (ориентиры):**
- Вход (обычный кран в РФ): часто **150–400 ppm** (зависит от города).
- После исправной RO-мембраны (до минерализатора): обычно **5–20 ppm**, часто **≤10% от входа**.
- После работающего K7M: TDS **заметно выше**, чем сразу после мембраны (часто +20…+80 ppm и более — зависит от ресурса модуля).

**Критерий мембраны (из вашего ТЗ):**

\[
\text{TDS}_{\text{выход чистой воды}} > 0{,}10 \times \text{TDS}_{\text{вход}}
\quad\Rightarrow\quad \text{менять K-50S}
\]

**Пример:** вход 200 ppm → порог **20 ppm**. Если чистый кран показывает 25 ppm → мембрана на замену.  
Если чистый кран 8 ppm при входе 200 → мембрана ок.

> **Нюанс Мориона:** кран чистой воды идёт через **K7M**. Для «чистого» TDS мембраны сними K7M и поставь **сервисную заглушку** из комплекта фильтра, затем замерь. Сравнение «с минералами / без» нужно именно так.

---

### 3.3. Инструкция: тест на свободный хлор (полоски)

**Общий порядок (Bestway / Маркопул / Reexo — одинаковая логика):**
1. Открой тубу, достань **одну** полоску, сразу закрой крышку (влага портит остальные).
2. Погрузи полоску в пробу **на 1 секунду** (Маркопул: на глубину 20–30 см в ёмкости; для стакана — полностью смочи подушечки).
3. Вынь **подушечками вверх**, воду **не стряхивай**.
4. Подожди **~15 секунд**.
5. Сравни цвет зоны **Cl / free chlorine** со шкалой на тубе.

**Критическое значение для препфильтров:** любой детектируемый свободный хлор после K5+K2 (**>0** на шкале, цвет не «нулевой») → **срочно менять K5 и K2**.

Диапазон шкалы Bestway 58142: свободный хлор **0–10 ppm**. Для фильтра тебе важен только факт: **0 vs не-0**.

#### Как взять пробу «после препфильтров, перед мембраной» на DWM-101S

Отдельного крана нет. Безопасный способ через штатные заглушки (см. [официальную инструкцию DWM-101S/102S](https://www.aquaphor.ru/userfiles/catalog_instructions/dwm101-102S_v6_print.pdf)):

1. Закрой кран на узле подключения («Закрыто»).
2. Открой кран чистой воды → сбрось давление.
3. Сними модуль **K-50S** (зажми стопорную кнопку, поверни против часовой).
4. Поставь **сервисную заглушку** мембраны из комплекта.
5. Сними **K7M**, поставь заглушку постфильтра (если есть) — чтобы проба не шла через минерализатор.
6. Кратко открой подачу и кран чистой воды, набери 50–100 мл в стакан.
7. Сразу сделай тест на хлор полоской.
8. Верни модули: K-50S и K7M на места, промой по инструкции 10–20 мин.

**Контроль:** параллельно протестируй воду из **обычного крана**. Если на входе хлор есть, а после K5+K2 — нет → препфильтры работают.

### 3.4. Decision tree

```
START
  │
  ├─① Замерь TDS_вход (обычный кран)  → запиши A ppm
  ├─② Замерь TDS_после_мембраны (кран чистой воды БЕЗ K7M / с заглушкой) → B ppm
  │     если B > 0.10 × A  →  ЗАМЕНИТЬ K-50S
  │
  ├─③ Поставь K7M обратно, замерь TDS_с_минералами → C ppm
  │     если C ≈ B (не вырос заметно, Δ < ~5–10 ppm)  →  ЗАМЕНИТЬ K7M
  │     если C заметно > B  →  K7M ок
  │
  ├─④ Тест хлора после K5+K2 (проба через заглушку мембраны)
  │     хлор обнаружен  →  СРОЧНО ЗАМЕНИТЬ K5 + K2
  │     хлор = 0        →  препфильтры ок по хлору
  │
  └─⑤ Календарь: с последней замены K5/K2 прошло ≥ 6 мес?
        да  →  превентивно ЗАМЕНИТЬ K5 + K2 (даже если хлор = 0)
        нет →  ничего по календарю
```

Можно менять несколько модулей за один заход, если сработали несколько веток.

**Критично при покупке мембраны:**
- Нужна именно **K-50S / КО-50S** (верхний дренаж, чёрная «шапка», **нет** отверстия снизу под дренажную трубку).

### Мини-корзина «только диагностика» (~400–2500 ₽)

1. TDS-3 (бюджетный или HM Digital)  
2. Полоски на свободный хлор (Reexo / Маркопул / Bestway 58142)

### Мини-корзина «типовое ТО раз в 6 мес»

- Комплект **без мембраны**: [K5+K2+K7M](https://www.aquaphor.ru/filters/cartridge/set-k5-k2-k7m) **или** отдельно K5+K2, если K7M ещё жив по TDS.

### Мини-корзина «мембрана умерла»

- [КО-50S](https://www.aquaphor.ru/filters/cartridge/ro-membrane-k-50s) + обязательно свежие [K5](https://www.aquaphor.ru/filters/cartridge/k5)+[K2](https://www.aquaphor.ru/filters/cartridge/k2) (иначе новая мембрана снова сгорит от хлора).

### Замена модулей (кратко)

Полная процедура: [PDF инструкция DWM-101S](https://www.aquaphor.ru/userfiles/catalog_instructions/dwm101-102S_v6_print.pdf).

1. Закрыть вход → открыть чистый кран → сбросить давление.  
2. Стопорная кнопка + поворот против часовой → снять модуль.  
3. Смочить уплотнительные кольца нового модуля, установить до щелчка по таблице позиций в инструкции.  
4. После замены K5/K2: промывка через заглушку мембраны **20–30 мин**.  
5. После замены мембраны: промывка по разделу инструкции (обычно десятки минут + слив бака).

## 5. Escalate

Эскалируй в **сервис Аквафор / установщика**, если:
- после замены нужных модулей TDS всё ещё >10% входа;
- нет воды / очень слабый поток при пустом баке (> порога из инструкции — обычно подозрение на засор/клапан);
- течи с корпуса/фитингов;
- не уверен, 101 или 101S.

**Что приложить:**
- фото модулей и серийника снизу корпуса;
- три числа: TDS вход / TDS без K7M / TDS с K7M;
- результат теста хлора (вход и после препфильтров);
- даты последних замен.

Портал: [aquaphor.ru/support](https://www.aquaphor.ru/support)

| TDS вход | TDS-3 | Обычный кран | ___ ppm | база | — |
| TDS после мембраны | TDS-3 | Чистый кран **без K7M** | ___ ppm | >10% от входа | → K-50S |

| Срок K5/K2 | Календарь | — | ___ мес | ≥6 | → K5+K2 превентивно |

## 7. Prevention note

- **K5+K2** — расходники защиты мембраны: менять **по времени (≤6 мес)**, не «когда вкус испортится». Хлор «съедает» K2 даже при малом расходе воды.
- После любого проскока хлора считай ресурс мембраны под угрозой — сделай TDS-контроль.
- Не экономь на препфильтрах ради дорогой K-50S.
